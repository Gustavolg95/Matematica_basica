# Matemática Básica

Site de revisão rápida de matemática básica, com resumos, macetes, flashcards e um quiz interativo.

**Acesse o site:** [Conceitos - Matemática Básica](https://gustavolg95.github.io/Matematica_basica/)

## Conteúdo

- **Frações** — soma, subtração, multiplicação e divisão
- **MDC e MMC** — regra de bolso, fatoração simultânea e macete
- **Potenciação e Radiciação** — propriedades de potência, expoente negativo, simplificação de raízes
- **Equação do 2º grau** — Bhaskara e o atalho de soma e produto
- **Vídeos** — seleção de vídeos curtos por tópico
- **Quiz** — 8 questões relâmpago com correção na hora

## Funcionalidades

- Navegação por abas entre os tópicos
- Flashcards com efeito de virar (clique para ver a resposta)
- Quiz interativo com pontuação final e opção de refazer
- Totalmente responsivo, sem dependências além de fontes do Google Fonts

## Tecnologias

- HTML5
- CSS3
- JavaScript puro (vanilla, sem frameworks)

## Como rodar localmente

```bash
git clone https://github.com/Gustavolg95/Matematica_basica.git
cd Matematica_basica
```

Depois é só abrir o `index.html` no navegador — não precisa de servidor nem instalação.

## Estrutura

```
├── index.html   # estrutura e conteúdo das seções
├── style.css    # tema "quadro-negro" e estilos dos componentes
├── script.js    # navegação, flashcards, vídeos e lógica do quiz
└── README.md    # explicação desse repositório
```
