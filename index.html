Frações — as 4 operações

Soma / Subtração

Denominadores iguais → só mexe em cima

Mesmo denominador: soma ou subtrai os numeradores e repete o denominador.

2/5 + 1/5 = 3/5

Denominadores diferentes: tire o MMC dos denominadores ou use o macete da multiplicação cruzada — funciona sempre, mesmo sem achar o MMC:

a/b + c/d = (a·d + b·c) / (b·d)
Multiplicação

"Multiplica reto"

Numerador vezes numerador, denominador vezes denominador. Não precisa de denominador comum.

a/b × c/d = (a·c) / (b·d)
Divisão

"Copia, inverte e multiplica"

Mantém a primeira fração igual, inverte a segunda (numerador vira denominador) e multiplica.

a/b ÷ c/d = a/b × d/c

Erro mais comum:

Simplifique sempre no final dividindo numerador e denominador pelo mesmo número. Se a fração puder virar número inteiro ou mais simples, transforme.

MDC e MMC

Regra de bolso

MDC = o que os números TÊM em comum (menor)

MMC = o menor número que é múltiplo de TODOS (maior)

Se a questão fala em "repartir em grupos iguais", "maior pedaço possível", "simplificar" → é MDC.
Se fala em "coincidir de novo", "acontecer juntos", "menor tempo/quantidade comum" → é MMC.

Como calcular

Fatoração simultânea

Fatore os números ao mesmo tempo, dividindo por primos (2, 3, 5, 7...):

  • MMC: divida todos os números pelo mesmo primo sempre que possível (se um não for divisível, repete ele). Multiplique todos os primos usados no final.
  • MDC: só pode dividir quando o primo divide todos os números ao mesmo tempo. Multiplique apenas esses primos comuns.
Macete de ouro

MDC × MMC = produto dos dois números

MDC(a,b) × MMC(a,b) = a × b

Ache um dos dois primeiro (o mais fácil) e descubra o outro por divisão — economiza tempo de prova.

Atalho para MDC de 2 números: Algoritmo de Euclides

Divide o maior pelo menor. Pega o resto. Divide o divisor anterior por esse resto. Repete até o resto ser 0 — o último divisor é o MDC.

Potenciação e Radiciação

Propriedades de potência (base igual)
  • Multiplicação → soma os expoentes: aᵐ · aⁿ = aᵐ⁺ⁿ
  • Divisão → subtrai os expoentes: aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • Potência de potência → multiplica os expoentes: (aᵐ)ⁿ = aᵐ·ⁿ
  • Expoente 0 → sempre dá 1 (a ≠ 0): a⁰ = 1
Expoente negativo

"Inverte e vira positivo"

a⁻ⁿ = 1/aⁿ   |   (a/b)⁻ⁿ = (b/a)ⁿ
Radiciação = potência ao contrário

Expoente fracionário vira raiz

a^(m/n) = ⁿ√(aᵐ)

Para simplificar raiz: decomponha o número em fatores primos e agrupe em grupos do tamanho do índice da raiz.

√72 = √(2³·3²) = √(2²·2·3²) = 2·3·√2 = 6√2

Erro mais comum

(a+b)² ≠ a² + b². É sempre a² + 2ab + b² (produto notável) — decore esse, cai muito.

Equação do 2º grau

Forma geral
ax² + bx + c = 0
Bhaskara

Fórmula completa

Δ = b² − 4ac
x = (−b ± √Δ) / 2a

Δ > 0 → duas raízes diferentes; Δ = 0 → uma raiz (raiz dupla); Δ < 0 → sem raízes reais.

Macete: Soma e Produto

Quando a = 1, nem precisa de Bhaskara

Procure dois números que somados deem −b e multiplicados deem c. Muito mais rápido em prova.

x² − 5x + 6 = 0 → números: 2 e 3 (2+3=5, 2·3=6)
Equações incompletas
  • c = 0 (falta o termo independente): coloque x em evidência → x(ax+b)=0 → x=0 ou x=−b/a
  • b = 0 (falta o termo com x): isole x² → x² = −c/a → tire a raiz dos dois lados
